# Sleep Voyage v3 References

These references support [the sleep voyage v3 plan](../../../docs/plans/sleep-voyage-v3.md). The user selected the tropical direction on November 23, 2026.

Two kinds of reference apply:

- **Style reference.** The supplied atoll recording defines the coral design, the coral palette, the stylization, and the near-shore water. It shows only a 30 m section of shore.
- **Structure references.** Real aerial photographs define the island shape, the reef platform, the reef edge, the jetty, and the vegetation layout. The recording does not show these items.

Use the style reference for the look of each object. Use the structure references for layout, proportion, and scale. Do not copy buildings, villas, or resort details from any image. The sleep island has no buildings.
